FACEIT cheat status on this site is a per-game configuration, not a single site-wide light. CS2, Valorant, Overwatch 2, and Rainbow Six Siege each have their own detection and availability fields. The place to read them together is the [FACEIT cheat status](/status/) hub.

This article explains the organization. It does not replace the board, and it does not invent new labels.

## Why status is split

Players looking for a well-rated, safe, undetected-oriented private listing still need the row that matches the title they queue. A CS2 label does not automatically apply to Siege. A Valorant row does not speak for Overwatch 2.

Keeping four rows in one file stops the blog, the FAQ, and the game pages from drifting into four different stories.

## What you will see on the status hub

Each game has:

- a detection state
- a run state
- a short display label
- an editorial note when one exists

Those values are maintained centrally. Homepage snapshots and game-page badges read the same source. If you want the latest configured wording, open the status page instead of trusting a sentence on a guide.

Labels such as undetected, monitoring, or updating are editorial states. They are how this site talks about a safe, current snapshot — not generated lab clocks or invented percentages.

## What monitoring and updating mean here

**Monitoring** means the title is treated as running while detection is watched.

**Updating** means a FACEIT cheat update is in progress for that game.

Read the live row before you treat either word as today’s headline. This guide only defines the categories so later update posts can point back here.

## Where to go after you read a label

The status hub is not checkout. After you confirm the configured row, open the matching game page for product detail, or use the [FAQ](/faq/) for organization questions.

Future update notes can sit in this Status & Updates category. They should still link to `/status/` instead of restating every game’s label in the article body.
